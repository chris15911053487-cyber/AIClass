# AI 实践学堂：首版架构

## 页面

- `/`：品牌首页与课程入口，内容读取已发布数据。
- `/courses`、`/courses/[id]`：课程筛选和独立课程详情。
- `/learn/[id]`：讲解、概念题、文本实战、提示、提交与历史记录。
- `/resources`：工具导航与课程 Skills。
- `/assistant`：真实模型服务接通后的自由问答。
- `/login`：大陆手机号＋短信验证码，首次验证自动注册。
- `/me`：个人进度、作品反馈、资料与退出登录。
- `/admin`：仅站点所有者可用的内容工作室；老师使用 ChatGPT 身份，与学员手机号身份分开。

## 数据与权限

D1 保存课程与草稿、学员、散列会话、短信验证码散列、频率限制、进度、提交及对话。
课程 → 课时 → 独立题目与任务。提交保存当时的课程版本与题目快照。
公开接口不返回答案、参考解法、预检关键词或内部 Skill 指令。
学员接口始终依据服务端会话中的用户 ID 查询，不接受客户端提供的用户 ID。
管理权限只由 ADMIN_EMAIL 与托管平台验证过的老师身份匹配授予。

## 编辑与评测

课程、课时、任务、测验、评分标准、Skill、工具与品牌文案可在后台编辑。
草稿与公开内容分开保存，发布后才对学员生效；编辑使用修订号检测冲突。
概念题按对应答案判定；文本作品仅提供关键词预检，不自动授予实战达标。
老师复核后记录达标或待修改。每次提交都保留，历史成绩不随课程更新重算。

## 外部服务与当前边界

- 用户尚无短信服务：手机号发送/验证返回清晰的未开通状态，不存在演示验证码。
- 已实现阿里云国内短信 SendSms 适配；正式接通前需签名、验证码模板、RAM 密钥和 OTP_SECRET，并做真实号码验收。
- AI 助教使用服务端 OpenAI Chat Completions 适配，需要 AI_API_KEY 与 AI_MODEL；尚未提供，所以自由问答关闭。
- Skills 是后台可维护的教学指令，与课时内容一起提供给模型；不声称具备未连接的搜索、文件或代码执行能力。
- 首版随堂实战支持文本和文本中的作品链接；视频支持 HTTPS 直链播放。文件上传、在线代码执行、付费课程和公开作品广场尚未实现。
- 当前上线为仅所有者可访问的私有验收版；不对学员公开招生。

## 配置与验证

环境变量见 `.env.example`；密钥通过 Sites 设置，不提交版本库。
本地数据库初始化：`npx wrangler d1 execute DB --local --config wrangler.local.json --file drizzle/0000_little_jazinda.sql`。
类型检查：`npx tsc --noEmit`。
规则测试：`node --experimental-strip-types --test tests/domain.test.ts`。
本地接口测试：`python3 tests/integration.py`；创建两个临时学员并在结束后清理。
上线包由 Sites 打包脚本生成，数据库结构由 Drizzle 迁移管理。

## 验证边界

尚未进行浏览器交互/视觉测试（用户未要求）；使用页面响应、类型检查与服务端接口测试验证。
WebMCP 提供只读课程目录接口；当前没有可用的 WebMCP 验证上下文，未声明已验证。
真实短信投递及模型对话需接通服务后验收。

验证结果：5 项规则测试、13 项学员接口检查、8 项老师后台检查已通过。老师测试覆盖草稿隔离、修订冲突、非法答案拒绝、发布可见性和版本递增。
